# 📈 CodeAlpha Stock Portfolio Tracker

## 📌 About the Project

The Stock Portfolio Tracker is a simple Python project developed as part of my CodeAlpha Python Programming Internship.

It allows users to select stocks, enter the number of shares they want to purchase, and calculate their total investment using predefined stock prices.

## ✨ Features

* Displays available stocks and their prices.
* Allows users to select stocks and enter quantities.
* Validates stock symbols and quantities.
* Calculates the investment for each stock.
* Displays the total investment.
* Saves the investment summary to a text file.

## 🛠️ Technologies Used

* Python 3
* VS Code

## ▶️ How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python stock_tracker.py
```

6. Enter the stock symbols and quantities when prompted.
7. Type `done` when you finish selecting stocks.

## 📁 Project Files

* `stock_tracker.py` — Main Python program.
* `portfolio_summary.txt` — Generated investment summary.
